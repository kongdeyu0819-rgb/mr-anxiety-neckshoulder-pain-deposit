# Release notes — alignment with the R3 revised manuscript

Prepared 2026-11-08 for the next archived version (proposed v1.0.6). The published Zenodo record 10.5281/zenodo.22774511 (v1.0.5) still contains the earlier content; this directory is the corrected package to be published.

Changed relative to v1.0.5:

1. Reverse-MR power script and result CSV corrected (see `CORRECTIONS.md`); power curve CSV added.
2. Repository title, description and metadata updated to the revised manuscript title and to the association (not causal) interpretation.
3. Outcome-side FinnGen analyses consistently described as exploratory cross-design analyses, not replication.
4. Author-identifying strings removed from LICENSE; `.zenodo.json` creators set to Anonymous for double-anonymous review.
5. Internal-only files moved out of the public package: the deposit operations guide, the reference-verification QA report and two text-rewriting logs.
6. AI-authoring comments removed from analysis scripts; internal Chinese commentary replaced with neutral English output.

Before publishing, note that Zenodo's GitHub integration may still expose the GitHub account name in the record metadata and archive filename. If double-anonymous review must be preserved, publish this package as a manual deposit with anonymous creators, or keep the DOI out of the anonymised manuscript files.
